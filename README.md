## Chay local
Backend:
1. `cd backend`
2. `npm install`
3. Tao file `.env` tu `.env.example`, dien `MONGODB_URI`
4. `npm start`

Frontend:
1. `cd frontend`
2. `npm install`
3. Tao `frontend/.env` voi `VITE_API_URL=http://localhost:5000`
4. `npm run dev`
